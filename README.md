# finansy — страницы для Google OAuth

Две статические страницы на GitHub Pages для приложения «Финансы» (код приложения — в приватном репозитории `finance-app`):

- `index.html` — домашняя страница приложения: что это и какой доступ к Google оно просит;
- `privacy.html` — политика конфиденциальности.

Зачем: Google не переводит OAuth-приложение (Google Auth Platform, проект `finansy-512809`) в рабочий режим «In production» без ссылок на домашнюю страницу и политику конфиденциальности. В режиме «Testing» доступ к Google Диску слетал бы каждые 7 дней.

Адреса:
- https://grigorijmetalnikov-ux.github.io/finansy/
- https://grigorijmetalnikov-ux.github.io/finansy/privacy.html

Авторизованный домен в Google: `grigorijmetalnikov-ux.github.io`.

Репозиторий **публичный** (бесплатный GitHub Pages работает только из публичных) — поэтому здесь только эти страницы: никакого кода, данных, ключей и личных контактов.

Чьё это приложение

«Финансы» — личное приложение для учёта денег. Оно работает на собственном сервере владельца и не является публичным сервисом: войти могут только владелец и люди, которым он сам выдал логин и пароль.

Какие данные хранятся

  • Данные учёта, которые вносит пользователь: счета, операции, покупки, платежи.
  • Фото чеков и скриншоты, которые пользователь загружает сам, и их расшифровка.

Всё это хранится на сервере владельца. Данные не продаются, не используются для рекламы и не передаются третьим лицам. Исключение — сервис распознавания текста на фото, которому отправляется изображение чека, чтобы прочитать его содержимое.

Google Диск

Если владелец подключил свой Google Диск, приложение использует Google Drive API и Google Sheets API с правом drive.file. Оно создаёт на Диске владельца папку «Финансы — чеки», кладёт туда копии фото чеков и их текстовую расшифровку и ведёт таблицу-реестр. Приложение видит только эти созданные им файлы; другие файлы, почта и данные аккаунта Google ему недоступны.

Данные, полученные через API Google, используются только для хранения этих резервных копий и не передаются никому. Использование информации, полученной через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Удаление и отзыв доступа

Доступ к Google Диску можно отозвать в любой момент на странице myaccount.google.com/permissions или кнопкой «Отключить» в админ-панели приложения. Файлы на Диске принадлежат владельцу Диска: он может удалить их сам. Данные на сервере удаляются вместе с кабинетом по запросу к владельцу приложения.

Privacy policy (English summary)

“Finansy” is a private personal finance app hosted on its owner's server; only the owner and people the owner invited can sign in. Data entered by users (accounts, transactions, receipt photos) is stored on that server, is never sold, never used for ads and never shared with third parties, except that receipt images are sent to a text-recognition service to read them. When the owner connects Google Drive, the app uses the Google Drive and Google Sheets APIs with the drive.file scope only: it creates a “Финансы — чеки” folder, stores receipt photo backups, text transcripts and a registry spreadsheet there, and cannot see any other files. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
